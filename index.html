About The Project

M.O.O.N Robotics is an intelligent agricultural monitoring robot designed to analyze soil conditions and environmental parameters in real time. The robot measures soil nutrients (NPK), humidity, air quality, and crop requirements to help farmers make better agricultural decisions.

This project combines robotics, sensors, and web technologies to create a smart farming monitoring system.
